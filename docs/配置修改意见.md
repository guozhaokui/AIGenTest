
## 配置分析报告

### 🔴 严重问题

#### 1. `inputMode` 和 `inputType` 概念重叠混淆

| 模型 | inputMode | inputType | 问题 |
|------|-----------|-----------|------|
| google_gemini_image | `both` | ❌无 | 缺少 inputType |
| doubao_seed3d | `image` | `image` | 冗余重复 |
| tripo_3d | `exclusive` | `text_or_image` | 语义重叠 |
| meshy_text_to_3d | `prompt` | `text` | 冗余重复 |

`inputMode` 的值 (`both`, `prompt`, `image`, `exclusive`) 和 `inputType` 的值 (`text`, `image`, `text_or_image`) 表达相似含义，应该合并。

#### 2. `options` 默认值与 `parameters.default` 重复冲突

```json
// tripo_3d - 同一个值定义了两次
"options": {
  "texture": true,      // ← 这里是布尔值
  "pbr": true
},
"parameters": [
  { "name": "texture", "default": "true" },  // ← 这里是字符串
  { "name": "pbr", "default": "true" }
]
```

```json
// meshy_text_to_3d - 默认值互相矛盾！
"options": { "mode": "preview" },        // ← preview
"parameters": [{ "name": "mode", "default": "full" }]  // ← full
```

#### 3. 布尔值类型不一致
- `options` 中用真正的布尔值：`true` / `false`
- `parameters` 中用字符串：`"true"` / `"false"`

---

### 🟡 中等问题

#### 4. 相同参数的 label 描述不一致

`personGeneration` 在两个 Gemini 模型中描述不同：
```json
// google_gemini_image
{ "label": "允许成年人", "value": "ALLOW_ADULT" }
{ "label": "禁止", "value": "DONT_ALLOW" }

// google_gemini_image2  
{ "label": "不生成儿童", "value": "ALLOW_ADULT" }  // 描述完全不同
{ "label": "无人物", "value": "DONT_ALLOW" }
```

#### 5. 语言混杂

同一文件中 label 中英混用：
- 中文：`"宽高比"`, `"纹理"`, `"网格拓扑"`
- 英文：`"Size"`, `"Steps"`, `"Guidance Scale"`, `"Model Version"`
- 混合：`"Orientation (3.0)"`

#### 6. `inputType` 值语义不清
- `image` vs `images` vs `multiview` - 区别不够直观
- `text_or_image` 表示互斥选择？还是都支持？

---

### 🟢 建议优化

#### 7. tripo_3d_multiview 版本号不一致
```json
"options": { "modelVersion": "v3.0-20250812" },
"parameters": [{ "default": "default" }]  // 默认值不匹配
```

---

## 改进建议

### 方案 A：简化字段定义

```json
{
  "id": "tripo_3d",
  "name": "Tripo3D",
  "driver": "tripo",
  
  // 合并为单一字段，清晰表达输入模式
  "input": {
    "types": ["text", "image"],  // 支持的输入类型
    "mode": "exclusive",          // exclusive | combined
    "default": "image"            // 默认选中
  },
  
  "output": "mesh",  // 简化 outputType
  
  // options 只放固定配置（不给用户改的）
  "options": {
    "useProxy": false
  },
  
  // parameters 放所有可调参数（带完整定义）
  "parameters": [
    {
      "name": "modelVersion",
      "label": "版本",
      "type": "select",
      "default": "default",
      "options": [...]
    }
  ]
}
```

### 方案 B：最小改动修复

1. **移除 `options` 中与 `parameters` 重复的默认值**
2. **统一 `inputType` 命名**：`text`, `image`, `image_exclusive`, `images_multi`, `images_multiview`
3. **移除 `inputMode`**（用 `inputType` 完全替代）
4. **统一布尔值用字符串**（前端表单更友好）
5. **统一语言为中文**
