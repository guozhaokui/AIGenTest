# 数据库迁移说明

## 概述

成功将 AIGC 项目的数据存储从 JSON 文件迁移到 SQLite 数据库，提升了性能和可扩展性。

## 迁移内容

### 之前（JSON 文件）
- `live-gen.json` - AI 生成历史记录（216KB，271条）
- `tasks-archive.json` - 归档任务（4KB，6条）

### 之后（SQLite 数据库）
- `aigc.db` - 统一的 SQLite 数据库（212KB）
  - `generations` 表 - 生成历史（268条）
  - `archived_tasks` 表 - 归档任务（7条）
  - 包含索引优化查询性能

## 主要改进

### 1. 性能提升
- **查询速度**：使用索引，查询速度大幅提升
- **并发处理**：SQLite 支持多读单写，避免文件锁问题
- **内存效率**：不需要一次性加载全部数据

### 2. 功能增强
- **复杂查询**：支持 SQL 查询，可以做统计分析
- **事务支持**：确保数据一致性
- **备份简单**：单个数据库文件，易于备份

### 3. 可扩展性
- **表结构**：规范的关系型数据结构
- **未来升级**：可轻松迁移到 PostgreSQL 等大型数据库

## 迁移步骤记录

### 1. 安装依赖
```bash
pnpm add better-sqlite3
```

### 2. 执行迁移
```bash
# 检查数据
node migrate-to-db.js --check

# 备份并迁移
node migrate-to-db.js --backup
```

### 3. 迁移结果
- ✅ 成功迁移 268 条生成记录
- ✅ 成功迁移 6 条归档任务
- ✅ 原文件已备份到 `data/backup/2026-01-20T07-01-33/`

## 新增 API 端点

### 生成记录 API
- `GET /api/generations` - 获取生成历史
- `GET /api/generations/stats` - 获取统计信息
- `GET /api/generations/info` - 获取数据库信息
- `POST /api/generations/cleanup` - 清理旧记录

### 使用示例
```javascript

GET /api/generations?limit=100

// 获取特定类型

// 获取统计
GET /api/generations/stats
```

### 自动归档流程
```
任务完成/失败/取消
    ↓
延迟归档（默认5秒）
    ↓
保存到 archived_tasks 表
    ↓
如果成功，同时保存到 generations 表
    ↓
从 tasks.json 删除
```

## 数据库结构

### generations 表
```sql
CREATE TABLE generations (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL,
  model_id TEXT,
  driver_id TEXT,
  prompt TEXT NOT NULL,
  params TEXT,
  result TEXT,
  status TEXT DEFAULT 'completed',
  created_at TEXT NOT NULL,
  completed_at TEXT,
  metadata TEXT
)
```

### archived_tasks 表
```sql
CREATE TABLE archived_tasks (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL,
  status TEXT NOT NULL,
  model_id TEXT,
  driver_id TEXT,
  prompt TEXT,
  params TEXT,
  progress INTEGER DEFAULT 0,
  result TEXT,
  error TEXT,
  driver_task_id TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT,
  started_at TEXT,
  completed_at TEXT,
  archived_at TEXT NOT NULL,
  metadata TEXT
)
```
