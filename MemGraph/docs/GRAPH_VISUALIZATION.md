# MemGraph 知识图谱可视化

## 功能概述

MemGraph 现在支持动态知识图谱可视化，通过向量相似度自动发现文档之间的关联关系。

## 核心特性

### 1. 动态节点扩展
- 不预存关系，运行时通过向量相似度动态发现
- 支持多层扩展（1层、2层）
- 智能去重，避免重复节点

### 2. 力导向布局
- 自动排布节点，避免重叠
- 节点之间有排斥力
- 连接的节点有吸引力
- 支持拖拽和缩放

### 3. 交互式探索
- 点击节点查看详细信息
- 点击"展开关联节点"按钮动态扩展
- 拖拽画布移动视图
- 鼠标滚轮缩放

## 使用方法

### 启动服务

```bash
cd D:\work\AIGenTest\MemGraph
python -m src.server
```

### 访问可视化页面

打开浏览器访问：
```
http://localhost:8800/static/graph-viewer.html
```

### 搜索和探索

1. **输入关键词搜索**
   - 例如："什么是 MemGraph"
   - 例如："向量检索原理"
   - 例如："FastAPI 使用"

2. **调整搜索参数**
   - **初始节点数**：搜索返回的主节点数量（1-10）
   - **扩展层数**：自动扩展的层数（0-2）
     - 0：只显示主节点
     - 1：主节点 + 一级关联
     - 2：主节点 + 一级关联 + 二级关联
   - **每层节点数**：每层扩展的节点数量（1-5）

3. **点击节点查看详情**
   - 左侧面板显示节点的完整信息
   - 包括：问题、解决方案、标签、元数据

4. **展开关联节点**
   - 选中节点后，点击"展开关联节点"按钮
   - 系统会找到与该节点相关的文档
   - 自动添加到图谱中

### 视图控制

- **拖拽画布**：鼠标左键拖动
- **缩放**：鼠标滚轮，或使用右上角的 +/- 按钮
- **重置视图**：点击右上角的 🔄 按钮

## 工作原理

### 1. 数据结构

```python
Document {
  id: 123,
  vectors: [v1, v2, v3, ...],  # 文档的所有向量
  metadata: {...}
}

# 反向索引
vector_to_doc = {
  vector_id: doc_id
}
```

### 2. 扩展算法

```
第0层（主节点）：
  用户查询 → 向量检索 → 找到最匹配的文档

第1层（一级关联）：
  主节点的向量 → FAISS 检索相似向量 → 找到相似文档

第2层（二级关联）：
  一级节点的向量 → FAISS 检索相似向量 → 找到相似文档
```

### 3. 相似度计算

- 使用文档的所有向量（段落、句子级）
- 批量 FAISS 检索
- 累积相似度得分
- 选择得分最高的文档作为关联节点

### 4. 布局算法

使用**力导向布局**：
- **排斥力**：所有节点互相排斥，避免重叠
- **吸引力**：有连接的节点互相吸引
- **中心力**：所有节点被吸引到画布中心
- **阻尼**：减速避免震荡

## API 接口

### 1. 搜索并扩展

```bash
POST /graph/search
{
  "query": "什么是 MemGraph",
  "initial_k": 5,
  "expand_layers": 1,
  "nodes_per_layer": 3
}
```

**响应**：
```json
{
  "success": true,
  "query": "什么是 MemGraph",
  "layers": {
    "layer0": [
      {
        "doc_id": 123,
        "problem": "MemGraph 介绍",
        "solution": "...",
        "layer": 0,
        "total_score": 0.95
      }
    ],
    "layer1": [
      {
        "doc_id": 456,
        "problem": "向量检索原理",
        "solution": "...",
        "layer": 1,
        "similarity_score": 0.82
      }
    ]
  }
}
```

### 2. 展开节点

```bash
POST /graph/expand
{
  "doc_id": 123,
  "top_k": 5
}
```

**响应**：
```json
{
  "success": true,
  "node": {
    "doc_id": 123,
    "problem": "...",
    "solution": "..."
  },
  "related_nodes": [
    {
      "doc_id": 456,
      "similarity_score": 0.85,
      ...
    }
  ],
  "count": 5
}
```

### 3. 获取节点信息

```bash
GET /graph/node/123
```

**响应**：
```json
{
  "success": true,
  "node": {
    "doc_id": 123,
    "path": "2026/01/example.md",
    "problem": "...",
    "solution": "...",
```

## 性能优化

### 1. 批量检索
- 收集所有向量后批量查询 FAISS
- 减少 API 调用次数

### 2. 限制向量数
- 每个文档最多使用 10 个向量进行扩展
- 优先使用段落级和句子级向量

### 3. 缓存机制
- 向量数据缓存在内存中
- 避免重复的数据库查询

### 4. 去重
- 自动排除已存在的节点
- 避免重复计算

## 注意事项

1. **首次使用需要重建索引**
   - 访问 http://localhost:8800 点击"重建索引"
   - 确保所有文档都有向量数据

2. **扩展层数建议**
   - 0层：精确查找
   - 1层：适度扩展（推荐）
   - 2层：广泛探索（节点可能较多）

3. **性能考虑**
   - 节点过多会影响渲染性能
   - 建议单次搜索节点总数 < 50

4. **浏览器兼容性**
   - 推荐使用 Chrome/Edge/Firefox
   - 需要支持 Canvas 2D 和 ES6+

## 故障排查

### Q: 搜索没有结果

**A**: 确保已重建索引，并且数据库中有文档。

### Q: 节点重叠

**A**: 等待几秒让布局算法收敛，或点击"重置视图"。

### Q: 展开节点没有反应

**A**: 该节点可能没有相关文档，或所有相关文档已在图中。

### Q: 页面卡顿

**A**: 减少节点数量，降低扩展层数或每层节点数。
