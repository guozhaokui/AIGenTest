## 问题

MCP 工具测试 - fetch 导入修复验证

## 解决方法

修复了 `backend/mcp-lessons/src/index.js` 中的 fetch 导入问题：

**问题**：
```javascript
import fetch from 'undici';  // 错误：导入整个模块
```

```javascript

```

修复后 MCP Client 可以正常通过 HTTP 调用 MemGraph 服务（localhost:8800）。
