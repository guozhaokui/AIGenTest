# IDE登录流程的实现方式

## 问题

IDE登录流程的实现方式

## 解决方法

IDE的登录需要两步：

1. **微信登录** - 用户通过微信扫码或授权完成第一步登录，获取微信登录的 token
2. **Token 交换** - 用微信登录获得的 token 去交换一个 layastore 的 token

这是一个两阶段认证流程，不能直接使用微信 token 访问 layastore 服务。
