## 问题

文本嵌入服务地址配置

## 解决方法

使用 Qwen3-Embedding-8B 模型做文本嵌入时，直接访问 GPU 服务器的嵌入服务地址：

```python
# config.py
EMBED_SERVICE_URL = "http://192.168.0.132:6014/embed/text"
EMBED_DIMENSION = 4096  # Qwen3-Embedding-8B 的向量维度
```

**架构说明**:
- GPU 服务器: `192.168.0.132:6014`
- 模型: Qwen3-Embedding-8B
- 输出维度: 4096 维
- 不需要通过 Gateway 中转，直接访问可以获得更好的性能

**测试方法**:
```python
import httpx

async def test_embed():
    url = "http://192.168.0.132:6014/embed/text"
    payload = {"text": "测试文本"}

    async with httpx.AsyncClient() as client:
        response = await client.post(url, json=payload)
        data = response.json()
        embedding = data["embedding"]

        print(f"向量维度: {len(embedding)}")
        print(f"向量范数: {np.linalg.norm(embedding):.4f}")
```

**注意事项**:
1. 确保返回的向量维度是 4096
2. 验证向量不是全零向量
3. 如果接口返回错误，应该抛出异常而不是返回零向量
