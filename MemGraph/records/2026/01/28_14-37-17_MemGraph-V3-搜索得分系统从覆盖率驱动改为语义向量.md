## 问题

MemGraph V3 搜索得分系统从覆盖率驱动改为语义向量驱动

## 解决方法

## 背景
用户反馈："我感觉覆盖率没有什么用，其实我搜索的话，只要存在就行，出现1次和10次并没有多大区别，整体的嵌入实际比覆盖率更有意义"

## 核心改进

### 1. N-gram 去重计数
**文件**: `src/activation_search.py:_aggregate_activations()`

```python
# 使用 set 去重，相同内容只计数一次
'matched_unique_ngrams': set(),

# 统计唯一 N-gram 数量
score['matched_ngrams'] = len(score['matched_unique_ngrams'])
```

### 2. 降低 N-gram 激活权重
```python
# OLD: 基于覆盖率的动态权重
coverage = matched_ngrams / query_ngram_count
score = activation_score * (0.7 + 0.3 * coverage)

# NEW: 固定低权重
score = activation_score * 0.3  # N-gram 只作为基础激活
```

### 3. 多粒度向量嵌入
**文件**: `src/knowledge_indexer.py`

新增 `ngram_vectors` 表:
```sql
CREATE TABLE ngram_vectors (
    ngram_content TEXT PRIMARY KEY,
    faiss_idx INTEGER UNIQUE,
    gram_size INTEGER
)
```

为 5-gram 及以上的片段生成向量（去重）:
```python
async def _index_ngram_vectors(self, ngrams):
    unique_ngrams = {}
    for ngram in ngrams:
        if ngram['gram_size'] >= 5:
            if content not in unique_ngrams:
                unique_ngrams[content] = ngram['gram_size']
    # 只为新片段生成向量...
```

### 4. 双层向量相似度计算
**文件**: `src/activation_search.py:_add_vector_similarity()`

```python
# 1. 文档级向量相似度（权重 10.0）
doc_similarity = cosine(query_vec, doc_vec)
total_score += doc_similarity * 10.0

# 2. N-gram级向量相似度（权重 5.0）
# 取匹配的 N-gram 中最高的向量相似度
max_ngram_similarity = max(cosine(query_vec, ngram_vec) 
                           for ngram in matched_unique_ngrams)
total_score += max_ngram_similarity * 5.0
```

## 最终得分公式
```
total_score = activation_score * 0.3           # N-gram 激活 (低权重)
            + doc_vector_similarity * 10.0     # 文档级向量 (主要)
            + ngram_vector_similarity * 5.0    # N-gram级向量 (辅助)
```

## 向量数量估算
15 个文档的实测数据:
- 文档级向量: 15
- 唯一 5-gram+ 片段: ~370
- **总向量数**: ~385 (25x 增长但绝对数量可控)

## 效果
- ✅ 语义匹配成为主导因素
- ✅ 避免高频词误导排序
- ✅ N-gram 去重避免重复计数
- ✅ 多粒度向量捕获细粒度语义
