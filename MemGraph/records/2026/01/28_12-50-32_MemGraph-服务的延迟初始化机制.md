## 问题

MemGraph 服务的延迟初始化机制

## 解决方法

在调试 MemGraph 服务时发现 FastAPI 的 `@app.on_event("startup")` 可能导致服务挂起返回 503 错误。

**解决方案**：实现延迟初始化（Lazy Initialization）

```python
# server.py
_initialized = False

async def ensure_initialized():
    """确保服务已初始化（延迟初始化）"""
    global indexer, search_engine, _initialized
    
    if _initialized:
        return
    
    indexer = KnowledgeIndexer()
    search_engine = ActivationSearch(indexer)
    
    # 同步现有文档
    if RECORDS_DIR.exists():
        await sync_existing_documents()
    
    _initialized = True

# 在每个 API 端点调用
@app.post("/record")
async def record_lesson(req: RecordLessonRequest):
    await ensure_initialized()  # 首次调用时初始化
    # ... 业务逻辑
```

**优点**：
1. 避免 startup 事件阻塞导致的 503 错误
2. 服务启动更快，延迟到首次请求时初始化
3. 更容易调试初始化问题

**注意**：需要在所有需要 indexer/search_engine 的端点前调用 `ensure_initialized()`
