## 问题

如何调试向量相似度为0的问题

## 解决方法

当发现搜索结果的向量相似度全是 0 时，按以下步骤排查：

## 1. 检查嵌入服务是否正常

```python
import httpx
import numpy as np

async with httpx.AsyncClient() as client:
    response = await client.post(
        "http://192.168.0.132:6014/embed/text",
        json={"text": "测试文本"}
    )
    embedding = response.json()["embedding"]
    print(f"维度: {len(embedding)}")
    print(f"范数: {np.linalg.norm(embedding):.4f}")
    print(f"全零检查: {np.all(np.array(embedding) == 0)}")
```

## 2. 检查错误处理逻辑

常见错误：捕获异常后返回零向量，隐藏了真实问题

```python
# ❌ 错误做法
try:
    embedding = await get_embedding(text)
except Exception:
    return np.zeros(EMBED_DIMENSION)  # 隐藏错误！

# ✅ 正确做法
try:
    embedding = await get_embedding(text)
    if np.all(embedding == 0):
        raise ValueError("收到全零向量")
    return embedding
except Exception as e:
    logger.error(f"嵌入失败: {e}")
    raise  # 让错误暴露出来
```

## 3. 检查维度配置

```python
# 确保配置的维度与模型输出一致
EMBED_DIMENSION = 4096  # Qwen3-Embedding-8B
# 不是 1024, 768 等其他值
```

## 4. 查看 FAISS 索引

```python
indexer = KnowledgeIndexer()
stats = indexer.get_stats()
print(f"向量数量: {stats['faiss_vectors']}")

# 检查向量范数
for i in range(indexer.index.ntotal):
    vec = indexer.index.reconstruct(int(i))
    norm = np.linalg.norm(vec)
    print(f"向量 {i}: 范数={norm:.4f}")
```
