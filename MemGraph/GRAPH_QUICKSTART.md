# MemGraph 知识图谱可视化 - 快速开始

## 🚀 3分钟快速体验

### 1. 启动 MemGraph 服务

```bash
cd D:\work\AIGenTest\MemGraph
python -m src.server
```

等待服务启动完成，看到：
```
╔════════════════════════════════════════════════════════════╗
║                   MemGraph 服务启动                        ║
║  服务地址: http://0.0.0.0:8800                            ║
╚════════════════════════════════════════════════════════════╝
```

### 2. 打开可视化页面

浏览器访问：
```
http://localhost:8800/static/graph-viewer.html
```

### 3. 开始搜索

在搜索框输入：
```
什么是 MemGraph
```

点击"搜索节点"按钮，你将看到：
- 🟣 紫色节点：匹配的主文档
- 🟢 绿色节点：相关联的文档（如果开启扩展）
- 连接线表示文档之间的关联

### 4. 交互探索

- **点击节点**：左侧面板显示详细信息
- **展开节点**：点击"展开关联节点"发现更多内容
- **拖拽画布**：鼠标拖动移动视图
- **缩放**：鼠标滚轮或右上角按钮

## 💡 使用技巧

### 技巧1：精确查找
- 扩展层数设为 0
- 只看最相关的结果

### 技巧2：发现关联
- 扩展层数设为 1
- 发现相关但你可能没想到的内容

### 技巧3：知识网络
- 从一个节点开始
- 逐个点击"展开关联节点"
- 手动构建感兴趣的知识网络

### 技巧4：视图整理
- 节点乱了？点击右上角 🔄 重置视图
- 节点太多？缩小范围重新搜索

## 📊 工作原理（简化版）

```
你的搜索 → 向量检索 → 找到最匹配的文档（紫色节点）
                ↓
         这些文档的向量 → FAISS 检索 → 找到相似文档（绿色节点）
                ↓
         继续扩展... → 更多相似文档（橙色节点）
```

**关键**：不需要预先定义关系，系统自动通过向量相似度发现关联！

## ❓ 常见问题

### Q: 搜索没有结果？
**A**: 数据库可能是空的。访问 http://localhost:8800 点击"重建索引"。

### Q: 节点重叠在一起？
**A**: 等待2-3秒，布局算法会自动分散节点。

### Q: 找不到可视化页面？
**A**: 确保访问 `/static/graph-viewer.html`，注意 `static` 路径。

### Q: 展开节点没反应？
**A**: 可能没有相关文档，或相关文档已经在图中了。
