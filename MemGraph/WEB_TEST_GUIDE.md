# MemGraph Web 测试面板使用指南

## 访问地址

启动 MemGraph 服务后，访问：

```
http://localhost:8800
```

或直接访问：

```
http://localhost:8800/static/index.html
```

## 功能说明

### 1. 📝 记录新经验

左上角的表单，用于添加新的经验记录。

**必填字段**:
- **问题描述**: 遇到了什么问题
- **解决方法**: 如何解决的，支持 Markdown 格式

**可选字段**:
- **角色**: AI 或 用户
- **项目名称**: 项目的简单描述
- **项目路径**: 项目目录的完整路径
- **标签**: 多个标签用逗号分隔，例如：`Python, FAISS, 搜索引擎`

### 2. 📊 统计信息

右上角显示当前知识库的统计数据：

- **文档数量**: 已索引的 Markdown 文档总数
- **N-gram总数**: 所有文档产生的 n-gram 片段总数
- **唯一N-gram**: 去重后的 n-gram 数量
- **FAISS向量**: FAISS 向量数据库中的向量数量

**操作按钮**:
- **刷新统计**: 重新加载统计数据
- **重建索引**: 清空数据库并重新索引所有 Markdown 文件（需要确认）

### 3. 🔍 搜索经验

下方的大面板用于搜索和查看结果。

**搜索参数**:
- **搜索关键词**: 输入要搜索的内容
- **结果数量**: 返回多少条结果（1-20）
- **最小得分**: 过滤掉得分低于此阈值的结果
- **向量搜索**:
  - **启用**: 使用激活式搜索 + FAISS 向量相似度（推荐）
  - **禁用**: 仅使用激活式 n-gram 搜索

### 4. 搜索结果详情

每条搜索结果显示以下调试信息：

#### 顶部标题栏
- **文件路径**: 经验记录的 Markdown 文件路径
- **总得分**: 右上角的紫色徽章，显示综合得分

#### 元数据（灰色背景区域）
- **角色**: AI 或 用户
- **项目**: 所属项目名称
- **时间**: 创建时间戳

#### 标签（蓝色标签）
显示所有相关标签

#### 得分细分（黄色背景区域）
这是调试的核心部分：

1. **激活得分**:
   - 基于 n-gram 匹配的激活得分
   - 数值越高表示关键词匹配越多

2. **向量相似度**:
   - 基于 Qwen3-8B 嵌入模型的语义相似度
   - 范围 0-1，越接近 1 表示语义越相似
   - 这是真正的语义理解能力

3. **匹配片段**:
   - 查询词匹配到的 n-gram 片段数量
   - 显示了激活了多少个知识节点

#### 内容预览
- **问题**: 显示前 300 字符
- **解决方法**: 显示前 500 字符（如果超过会显示省略号）

## 综合得分计算公式

```
总得分 = 激活得分 × 覆盖率 + 向量相似度 × 3.0
```

**说明**:
- **激活得分**: 匹配的 n-gram 数量和质量（考虑粒度权重）
- **覆盖率**: 查询词被文档覆盖的比例
- **向量相似度**: 语义层面的相关性（权重 3.0）

## 使用场景示例

### 场景1: 快速记录开发中遇到的问题

1. 在 **记录新经验** 表单中填写：
   - 问题: "FastAPI 静态文件挂载后无法访问"
   - 解决方法: "需要在路由定义之后挂载静态文件，并确保目录存在"
   - 标签: "FastAPI, 静态文件, 部署"

2. 点击 **记录经验** 按钮

3. 系统会自动：
   - 生成 Markdown 文件
   - 提取 n-gram
   - 生成 Qwen3-8B 嵌入向量
   - 存入 SQLite 和 FAISS

### 场景2: 搜索相关经验

1. 在搜索框输入: "fastapi 静态"

2. 系统会：
   - 分词: ["fastapi", "静态", "fastapi 静态"]
   - 激活匹配的 n-gram 节点
   - 计算激活得分
   - 生成查询的向量
   - 在 FAISS 中检索相似向量
   - 综合排序

3. 查看结果：
   - 观察 **激活得分**: 看关键词匹配情况
   - 观察 **向量相似度**: 看语义理解能力
   - 观察 **匹配片段**: 看激活了多少节点

### 场景3: 调试搜索效果

**问题**: 搜索"登录流程"没有找到预期的文档

**调试步骤**:

1. 尝试不同参数：
   - 降低 **最小得分** 阈值（例如从 0.1 降到 0.05）
   - 增加 **结果数量**（例如从 5 增加到 10）

2. 对比向量搜索开关：
   - **启用向量搜索**: 查看向量相似度得分
   - **禁用向量搜索**: 仅查看激活得分
   - 对比两种模式找到最佳设置

3. 检查文档：
   - 查看匹配到的文档的 **标签** 是否合理
   - 查看 **问题预览** 和 **解决方法预览** 是否包含相关内容

4. 重建索引：
   - 如果怀疑索引有问题，点击 **重建索引**
   - 等待重建完成后重新搜索

## 技术亮点展示

### 1. 多粒度 N-gram 激活

搜索 "claude code mcp" 时，会激活：

- **字符 2-gram**: "cl", "la", "au", "ud", "de", "co", "od", "de", "mc", "cp"
- **字符 3-gram**: "cla", "lau", "aud", "ude", "cod", "ode", "mcp"
- **词 2-gram**: "claude code", "code mcp"
- **词 3-gram**: "claude code mcp"
- **句子级别**: 整个查询作为一个句子

### 2. 真实语义嵌入

- 搜索 "登录" 时，也能找到 "认证"、"鉴权" 相关文档
- 搜索 "优化性能" 时，也能找到 "提升速度"、"加快响应" 相关文档
- 这是 Qwen3-8B 嵌入模型的语义理解能力

### 3. 双重排序机制

- **激活得分**: 快速过滤大量无关文档
- **向量相似度**: 精准定位语义相关文档
- 结合两者优势，既快又准

## 注意事项

1. **AI Gateway 必须运行**:
   - MemGraph 依赖 `http://localhost:8899/embed/text/qwen3-8b` 生成向量
   - 如果 AI Gateway 未启动，向量搜索会失败

2. **首次使用会较慢**:
   - 第一次搜索需要生成查询向量
   - 第一次记录需要生成文档向量
   - 后续会有缓存加速

3. **浏览器兼容性**:
   - 推荐使用 Chrome、Edge、Firefox 最新版
   - 需要支持 ES6+ 和 Fetch API

4. **CORS 已配置**:
   - 允许所有来源访问 API
   - 生产环境需要修改 `allow_origins`

## 故障排查

### 问题1: 页面无法加载

**原因**: MemGraph 服务未启动

**解决**:
```bash
cd D:\work\AIGenTest\MemGraph
python start.py
```

### 问题2: 搜索返回空结果

**原因**: 索引未构建或查询词太短

**解决**:
- 点击 **重建索引** 按钮
- 使用更长的查询词（至少 2 个字）

### 问题3: 记录经验失败

**原因**: AI Gateway 未运行或嵌入服务失败

**检查**:
```bash
curl http://localhost:8899/health
```

**解决**: 确保 AI Gateway 服务正常运行

### 问题4: 向量相似度显示 "-"

**原因**: 未启用向量搜索或 FAISS 索引为空

**解决**:
- 确保 **向量搜索** 选项为 **启用**
- 点击 **重建索引** 重新生成向量
