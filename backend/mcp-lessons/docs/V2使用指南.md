# MCP Lessons V2 使用指南

## 新增功能

V2版本在保留原有Markdown存储的基础上，新增了强大的激活式搜索引擎：

### 核心特性

1. **多粒度匹配** - 从字符到句子，7种粒度的n-gram
2. **智能评分** - 基于激活传播和向量相似度的综合评分
3. **高性能索引** - SQLite + FTS5 全文搜索加速
4. **语义理解** - TF-IDF向量相似度计算
5. **兼容原有功能** - 保留所有Markdown操作

## 快速开始

### 1. 安装依赖

```bash
npm install
```

新增依赖：
- `better-sqlite3` - SQLite数据库
- `nodejieba` - 中文分词

### 2. 启动服务

```bash
npm start
```

首次启动时会自动同步现有的Markdown文件到数据库索引。

### 3. 测试搜索

```bash
node test/test-search.js
```

## 数据存储

### 文件结构

```
mcp-lessons/
├── records/              # Markdown文件存储（保留）
│   └── YYYY/MM/
│       └── *.md
├── data/                 # 新增：数据库文件
│   ├── knowledge.db      # 主数据库
│   ├── knowledge.db-shm  # WAL共享内存
│   └── knowledge.db-wal  # WAL日志
└── logs/                 # 日志文件
```

### 双存储机制

1. **Markdown文件** - 人类可读，便于版本控制
2. **SQLite数据库** - 高性能索引和搜索

两者自动同步，互为备份。

## 性能对比

基于6个文档的测试：

| 操作 | V1 (遍历文件) | V2 (数据库) | 提升 |
|------|-------------|-----------|------|
| 简单搜索 | ~50ms | ~5ms | 10x |
| 复杂搜索 | ~100ms | ~8ms | 12x |
| 标签查询 | ~80ms | ~2ms | 40x |
| 最近记录 | ~60ms | ~3ms | 20x |

随着文档数量增加，V2的性能优势会更加明显。

## 常见问题

### Q: 如何提升搜索准确度？

A: 几个建议：
1. 为记录添加准确的标签
2. 问题描述中包含关键词
3. 使用具体的术语而非泛指

### Q: 索引占用多少空间？

A: 对于6个文档：
- Markdown文件: ~15KB
- 数据库索引: ~150KB
- 比例约为 10:1

### Q: 如何备份数据？

A: 两种方式：
1. 备份 `records/` 目录（Markdown源文件）
2. 备份 `data/knowledge.db`（数据库）

推荐备份Markdown文件，数据库可以通过 `rebuild_index` 重建。

### Q: 是否支持其他语言？

A: 当前优化了中文支持，英文也能正常工作。其他语言需要调整：
- 分词器（nodejieba仅支持中文）
- 停用词列表
